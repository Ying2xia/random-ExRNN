# Data preparation

Synthetic simulation data are generated by `code/extremilefed/simulation.py` and need no download.

For the application experiments, obtain data from the original sources:

- [CASdatasets French motor third-party liability data](https://dutangc.github.io/CASdatasets/reference/freMTPL.html): the `freMTPL2freq` policy table and `freMTPL2sev` severity table, exported as CSV without an added row-index column.
- [UCI Beijing Multi-Site Air Quality, dataset 501](https://archive.ics.uci.edu/dataset/501/beijing+multi+site+air+quality+data): the twelve station CSV files, extracted without modifying their contents.

Expected layout:

```text
data/
  freMTPL2freq.csv
  freMTPL2sev.csv
  beijing/
    PRSA_Data_Aotizhongxin_20130301-20170228.csv
    ... remaining eleven station CSVs ...
```

The frequency-table columns are `IDpol, ClaimNb, Exposure, VehPower, VehAge, DrivAge, BonusMalus, VehBrand, VehGas, Area, Density, Region`; severity uses `IDpol, ClaimAmount`. The application loader checks required columns before constructing the published splits.

`checksums.json` identifies the exact CSV byte streams used for the recorded experiments. The frozen evaluation entry point verifies these hashes before fitting. Preserve the original row order and numeric values when preparing insurance CSVs; CSV exporters may produce different bytes even for equivalent tables. Use `code/check_data.py` to inspect the supplied files and checksums. The original application development entry point accepts a newly prepared dataset in a fresh output directory.

Raw files and processed arrays stay local and are excluded by `.gitignore`. No real observations are bundled in `published_results/`.
